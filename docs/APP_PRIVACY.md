# Apple - App Privacy ("nutrition label") draft

| Item | Plugin-less build | With AdMob |
|---|---|---|
| Data Not Collected | yes | no |
| Identifiers - Device ID (IDFA) | - | Third-Party Advertising; not linked to identity; used for tracking if ATT granted |
| Usage Data - Product Interaction | - | Third-Party Advertising / Analytics (AdMob) |
| Location - Coarse | - | AdMob (IP-derived) |
| Purchases | handled by StoreKit; no purchase history collected by us | same |
| Tracking | no | only after the App Tracking Transparency prompt (`NSUserTrackingUsageDescription` must be added with the SDK) |

`PrivacyInfo.xcprivacy` is generated by Godot's iOS template; add the SDK's required-reason API declarations when AdMob is added. Privacy policy URL: https://omer-poyraz.github.io/frogpop-bubble-quest/privacy-policy/
